📚 A Smarter Way to Learn JavaScript — Practice

This repository contains my JavaScript learning and practice based on A Smarter Way to Learn JavaScript by Mark Myers.

The purpose of this repository is to practice JavaScript concepts chapter by chapter and maintain a practical record of my learning journey.

🎯 Learning Approach

For each group of chapters, I will:

📖 Study the concepts
🧠 Understand the logic
💻 Write practice code
📝 Take quizzes
🔍 Review mistakes
📁 Add the practice code to this repository

The number of chapters in each practice file may change according to the difficulty of the topics.

Easy topics → around 5 chapters
Medium topics → around 3–4 chapters
Difficult topics → around 2–3 chapters
Important concepts → separate practice when necessary
